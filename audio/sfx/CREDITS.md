# Sound effect credits (Last Pup Standing)

Every file here is **CC0 1.0 (public domain)**: no attribution required; listed anyway.
Sources are the downloaded packs in `Ruben HQ/Asset Library/audio/sfx/`. Each file was converted with ffmpeg to mono
44.1 kHz Ogg Vorbis (q3) and loudness-matched (gain so the mean is -18 dB, peak capped at -1 dB); a few were trimmed
(trim column, seconds, 0.25 s fade-out). Mix volumes per sound live in `src/audio/sfx.ts` (`SFX`).
